# gpt-image-2-architectural-diagrams

A personal Codex Skill for creating, editing, and reviewing evidence-bounded
non-render architectural graphics with GPT Image 2, including schematic
plans, sections, elevations, axonometrics, assemblies, process diagrams, and
same-scale comparisons.

The repository root is the Skill package. `SKILL.md` is the entry point;
`references/` and `agents/` contain the routed architectural guidance and
metadata. The package is intended to be paired with the system image
generation workflow when an image tool is actually used.

The Skill treats AI output as an expression aid rather than measured CAD/BIM,
construction documentation, or verified project evidence. Project-specific
evidence rules and human review remain authoritative.
